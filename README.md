# 042테일러링 웹사이트 — RGB팀

이 저장소는 **042테일러링** 브랜드 웹사이트를 만드는 **RGB팀** 작업 공간입니다.

배포 주소: https://042tailoring-rgb.progen-web.workers.dev

---

## 처음 시작하는 법 (순서대로)

**1. 준비 (한 번만)**
- Orca 열기 → ChatGPT는 **PROGEN** 워크스페이스로 로그인
- GitHub 로그인 (Orca가 안내함)
- 이 저장소를 Orca에서 열기(clone)

**2. 만들기**
- 이미 기본 사이트 뼈대(`index.html`)가 들어 있습니다. 빈 화면이 아닙니다.
- Codex에게 우리말로 시키세요. 예:
  - "히어로 문구를 우리 브랜드 슬로건으로 바꿔줘"
  - "룩북에 제품 카드 6개로 늘리고 사진 자리 만들어줘"
  - "전체 색을 따뜻한 베이지 톤으로 바꿔줘"

**3. 확인 (미리보기)**
- 저장한 뒤 `index.html`을 브라우저로 열어 확인하세요.
- 이 미리보기는 **배포 횟수를 쓰지 않습니다.** 마음껏 확인하세요.

**4. 배포 (push)**
- 진짜 완성된 지점에서만 **push** 하세요.
- push하면 사이트가 **자동으로 갱신**됩니다. 다른 설정은 건드릴 필요 없습니다.

---

## 꼭 지킬 규칙

- **작은 수정마다 push하지 마세요.** 브라우저 미리보기로 확인하고, **완성 단위로만 push**하세요. (배포 횟수를 아끼기 위함)
- `index.html`, `style.css`, `script.js` 이 세 파일을 주로 수정합니다.
- 막히면 Codex에게 그대로 물어보세요. "왜 안 떠?", "이거 고쳐줘" 처럼요.

## 파일 설명

| 파일 | 무엇 |
|---|---|
| `index.html` | 사이트 내용(글·구조) |
| `style.css` | 디자인(색·글꼴·간격) |
| `script.js` | 공통 움직임(효과) |
| `products.html` | 제품 목록 UI |
| `product.html` | 브랜드가 편집기에서 만든 상세 내용을 보여주는 제품 상세 UI |
| `portfolio.html` | 브랜드가 편집기에서 만든 한 페이지 포트폴리오 UI |
| `style.css`의 `제품 상세페이지` 영역 | 상세페이지 디자인 |
| `catalog.js` | 제품 데이터 로딩·안전 처리(수정 금지) |
| `products.json` | 브랜드 담당자가 사이트 관리자에서 관리하는 제품 데이터 |
| `portfolio.json` | 브랜드 담당자가 사이트 관리자에서 관리하는 포트폴리오 본문 |
| `/admin` | 브랜드 담당자용 제품·포트폴리오 편집기 |

## 브랜드 제품 관리

- 접속 주소: https://042tailoring-admin.progen-web.workers.dev/admin
- 브랜드 담당자는 GitHub 계정 없이 관리자 비밀번호만으로 로그인합니다.
- 초기 비밀번호는 `0000`입니다. 필요할 때 관리자 상단의 **비밀번호 변경** 버튼에서 바꿀 수 있습니다.
- 제품을 저장하면 같은 브랜드의 연결된 팀 저장소에 기록되고 자동 배포 후 모든 시안에 함께 반영됩니다.
- 상단 **포트폴리오** 탭에서 블로그 글처럼 한 페이지를 작성할 수 있고, 저장하면 연결된 모든 시안에 함께 반영됩니다.
- 학생은 `admin.html`, `admin.css`, `admin.js`, `admin-config.json`, `brand-config.js`, `worker.js`, `products.json`, `portfolio.json`, `portfolio.js`, `wrangler.jsonc`, `wrangler.admin.jsonc`를 수정하지 않습니다.
